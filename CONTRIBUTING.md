Contributing

Hi!

Thanks for wanting to contribute to my projects!

Everyone is welcome to contribute, whether you're reporting a bug, suggesting an idea, or improving the code.
Reporting a bug

If you find a bug, please open an issue using the Bug Report template.

Try to include:

- A clear description of the problem
- The steps needed to reproduce it
- What you expected to happen
- Your operating system and Python version
- Any screenshots or additional information that could help

Suggesting a feature

Have an idea for a new feature? Open an issue using the Feature Request template.

Explain what you'd like to add and why you think it would be useful.
Making changes

If you want to contribute code:

- Fork the repository.
- Create a new branch for your changes.
- Make your changes.
- Test your changes to make sure everything works.
- Commit your changes with a clear message.
- Open a Pull Request.

Pull Requests

When opening a Pull Request, please explain:

What you changed
Why you changed it
Any important details about your changes

Please make sure your code works before submitting the Pull Request.
General guidelines

- Keep your code clear and understandable.
- Don't include unnecessary changes.
- Respect other contributors.
- Follow the project's existing coding style when possible.
- Don't submit code that you know is broken or malicious.

Thanks for contributing! ❤️
