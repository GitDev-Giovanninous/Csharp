Security Policy
Reporting a security issue

If you find a security vulnerability in one of my projects, please report it privately instead of creating a public issue.

You can contact me using the email address provided in my GitHub profile.

Please include:

- A description of the vulnerability
- The project and version affected
- Steps to reproduce the issue, if possible
- Any other information that could help me understand the problem

Please do not publicly share details about a security vulnerability before it has been addressed.
Scope

This policy applies to the projects and code contained in this repository.

Thank you for helping keep my projects safe!
